Network Forensics & Threat Intel Packet Capture Pipeline

pcap-analyzer — Network Forensics & Threat Telemetry Pipeline

Project Repository

Built a Python-based network forensics pipeline using Scapy, SQLite, and the VirusTotal REST API to parse raw packet capture (.pcap) files, extract behavioral network indicators, store structured forensic artifacts locally, and enrich suspicious external endpoints with threat intelligence telemetry.

1. Packet Artifact Extraction

Parses `.pcap` captures with Scapy to extract source/destination IP conversations, protocol distributions, port activity, and DNS/HTTP flow metadata.

2. SQLite Storage & Caching

Stores parsed session artifacts and resolved IP reputation results in a local SQLite database to avoid duplicate lookups and respect API rate quotas.

3. VirusTotal Enrichment

Queries external public IPs against the VirusTotal v3 REST API and outputs structured forensic summaries highlighting flagged connections.

Lab Case Study — Brute-Force & Suspicious Process Triage
Alert: Multiple Failed Logins Followed by Success MITRE: T1110 (Brute Force) → T1059.001 (PowerShell)
index=sec_events (EventCode=4625 OR EventCode=4624) Host="WKSTN-04" | stats count(eval(EventCode=4625)) as Failed, count(eval(EventCode=4624)) as Success by src_ip, Account_Name

Triage Outcome: Escalated as True Positive; documented host isolation, credential reset, and egress IP block.
